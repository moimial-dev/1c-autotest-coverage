АВТОТЕСТ1С — КРАТКОЕ ОПИСАНИЕ
=============================

Внешняя обработка (.epf) для автоматического тестирования конфигураций 1С.
Работает на любой конфигурации без предварительной настройки: подключились
к базе, нажали «Выполнить прогон» — получили результат. Писать сценарии не нужно.


ЧТО ДЕЛАЕТ
----------

1. Автопрогон «из коробки».
   Строит карту объектов конфигурации и сама проверяет каждый: открытие форм,
   создание объектов, проведение документов, права, персональные данные,
   изоляцию контура. Ни одной строки сценария вручную.

2. Генератор UI-сценариев для Vanessa Automation.
   Собирает .feature-файлы по карте объектов: списки, формы создания, отчёты,
   команды разделов, печатные формы, ввод на основании. Набор обновляется вместе
   с конфигурацией и не требует ручной поддержки.

3. Отчётность.
   Карта объектов, покрытие, риск-карта, покрытие интерфейса. Выгрузка в JSON
   (для CI), HTML (для чтения) и MXL (для печати).


ЧЕМ ПОЛЕЗНА
-----------

  * Набор собирается под конкретного пользователя: в него попадают только
    объекты, доступные ему по правам и видимые в его разделах меню. Сценарии
    выполняются под этим же пользователем.
  * Объекты, скрытые выключенными функциональными опциями, пропускаются —
    проверки не падают на том, чего в интерфейсе нет.
  * Исключения объектов в формате файлов (как в xddTestRunner): строка —
    имя объекта, при необходимости с типом проверки, поддерживаются маски.
  * Разбор результатов прогона: штатные отказы конфигурации («только
    на основании», «не выбран сегмент») уходят в исключения автоматически,
    остальные падения остаются человеку. Настоящие дефекты исключениями
    не прячутся никогда.
  * Критичность объектов 1–3: быстрый набор на каждый коммит и полный на ночь.
  * Разделение наборов на читающие и пишущие (тег @ИзменяетДанные) — пишущий
    можно не гонять на копии рабочей базы.
  * Раскладка по потокам для параллельного прогона, балансировка по числу
    сценариев.
  * Пакетный режим для CI/CD: прогон и выгрузка отчётов без участия человека.


КАК УСТРОЕНЫ СЦЕНАРИИ
---------------------

Сценарии ждут событий, а не отсчитывают паузы: открытия формы по имени,
появления нового окна, заполнения табличного документа. Таймаут — верхняя
граница на худший случай, а не время простоя.

Печать проверяется по-настоящему: команда печати берётся у БСП (а не угадывается
по макетам), документ для печати ищется запросом при прогоне (проведённый,
непомеченный), а проверяется не факт открытия окна, а заполнение печатной формы
данными — пустая печатная форма и есть тот дефект, ради которого пишется тест.


ТРЕБОВАНИЯ
----------

  * Платформа 1С:Предприятие 8.3 (проверено на 8.3.27).
  * Для генерации сценариев и их прогона — Vanessa Automation (проверено
    на 1.2.043).
  * Для проверки печатных форм — библиотека стандартных подсистем (БСП)
    в конфигурации.
  * Права: полный прогон — администратор; генерация набора под пользователя —
    достаточно чтения метаданных.

Проверено на «1С:Розница» 2.3.


ОГРАНИЧЕНИЯ
-----------

  * Видимость команд панели функций из метаданных не читается — лечится
    исключениями или выключенным флажком «Команды разделов».
  * Выбор печатной формы — эвристика: предпочитается команда с признаком
    «основная», но если конфигурация их не проставляет, берётся первая.
  * Команды печати с диалогом параметров сценарий не проходит — такие объекты
    вносятся в исключения.
  * Набор собирается под конкретную базу (права, опции, состав данных);
    при смене базы его перегенерируют.


СОСТАВ ПОСТАВКИ
---------------

  АвтоТест1С.epf                     собранная обработка
  АвтоТест1С. Инструкция.doc         инструкция пользователя со скриншотами
  Исходники\                         исходный код в формате выгрузки конфигуратора
  Документация\                      полная документация и ТЗ в txt
  Скриншоты\                         иллюстрации к инструкции

Сборка из исходников:

    1cv8.exe DESIGNER /F<пустая база> /LoadExternalDataProcessorOrReportFromFiles
        "Исходники\АвтоТест1С.xml" "АвтоТест1С.epf"
